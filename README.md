# Turbo Gol

Telefon için arabalı futbol. Botlara karşı 1v1, 2v2 veya 3v3 oynanır.

- **Garaj:** Klasik ya da Sukuna seç.
- **Klasik:** biraz daha hızlı, turbosu kendiliğinden dolar. Ultisi **Kesin Gol**: bir sonraki dokunuşta top kaleye kıvrılır.
- **Sukuna:** ALEV ve CLEAVE yetenekleri. Ultisi **Alan Genişletme**: 4 saniye boyunca rakip takım patlar.
- **Ulti:** sırayla herkese bir kere gelir, önce geride olan takıma.
